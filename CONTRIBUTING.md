# Mitarbeit

Inhalte und Seiten können über den separat geteilten Bearbeitungslink online bearbeitet werden. Für Codeänderungen dieses Repository forken, einen Branch erstellen und einen Pull Request öffnen. Für direkten Schreibzugriff kann der Eigentümer GitHub-Accounts einladen.

Vor Änderungen `npm ci`, danach `npm test` und `npm run build`. Text-, Seiten- und Medien-IDs stabil halten; bestehende Online-Inhalte müssen bei Codeupdates erhalten bleiben. Keine Bearbeitungsschlüssel, Original-E-Mails, Lovable-Zugangstokens oder Cloud-Zugangsdaten veröffentlichen. Ausschliesslich Worker und R2-Bucket dieses Projekts verwenden.
